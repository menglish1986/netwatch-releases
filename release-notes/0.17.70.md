# NetWatch 0.17.70

## Highlights

- Added a PRTG-inspired global monitoring shell with live counts for Down, Acknowledged, Warning, Up, Paused, Unusual, and Undefined sensors.
- Added S, M, L, and XL device views: compact tree and status table, sensor chicklets, channel readings with bounded sparklines, and an accessible Sunburst hierarchy.
- Added global search, hierarchy breadcrumbs, and object context actions for checks, pausing, acknowledgements, dependencies, cloning, and deletion.
- Added exact summary counts, primary channel readings, and bounded recent sparkline values to the state API.
- Added timed sensor and device pauses with automatic resume. Sensor deletion now cleans up dependencies and related references while retaining audit and notification records.
- Updated asset cache keys to 0.17.70.

## Verification

- Automated suite: 120 tests passed.
- Summary API benchmark with 5,005 sensors: 44.75 ms median and 52.51 ms p95 over 30 warm runs.
- Installer archive verified to include the server, core probe, and updater executables.

Browser rendering time and heap usage were not measured with DevTools for the 5,005-sensor fixture. Large L and XL views should receive a browser profiling pass on a staging Core.
